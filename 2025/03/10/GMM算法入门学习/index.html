GMM算法入门学习

一、正态分布基础

### 1. 随机变量 正态分布是一种连续型随机变量的分布，若随机变量\(X\)服从概率密度函数： \[ f(x) = \frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}} \] 则称\(X\)服从均值为\(\mu\)，方差为\(\sigma^2\)的正态分布，记为\(X\sim N(\mu, \sigma^2)\)。[^1] 从函数中可以看出，\(f(x)\)的对称轴为\(x=\mu\)，在对称轴处取得最大值\(Max=\frac{1}{\sqrt{2\pi}\sigma}\)。 所以参数的几何意义如下：\(\mu\)决定函数的对称轴位置，\(\sigma\)决定变量分布的离散程度（值越大，离散程度越大），如图1。 ![alt text](figures/12.png)
图1：不同参数的正态分布密度函数
### 2. 随机向量 正态分布的概念可以推广到多维情形。若随机向量 \(\boldsymbol{X} = (X_1, X_2, \dots, X_n)^\top\) 服从概率密度函数： \[ f(\boldsymbol{x}) = \frac{1}{(2\pi)^{n/2} |\boldsymbol{\Sigma}|^{1/2}} e^{-\frac{1}{2}(\boldsymbol{x}-\boldsymbol{\mu})^\top \boldsymbol{\Sigma}^{-1}(\boldsymbol{x}-\boldsymbol{\mu})} \] 则称 \(\boldsymbol{X}\) 服从**多元正态分布**，记为 \(\boldsymbol{X} \sim N(\boldsymbol{\mu}, \boldsymbol{\Sigma})\)，其中： - \(\boldsymbol{\mu} = (\mu_1, \mu_2, \dots, \mu_n)^\top\) 为均值向量，决定分布的中心位置。 - \(\boldsymbol{\Sigma}\) 为协方差矩阵（对称正定矩阵），控制分布的离散程度和各维度间的相关性。 #### 参数的几何意义 1. **均值向量 \(\boldsymbol{\mu}\)**： 决定多维空间中的分布中心，对应于密度函数的对称中心。在几何上表现为多维正态分布钟形曲面的峰值位置。 2. **协方差矩阵 \(\boldsymbol{\Sigma}\)**： - 对角线元素 \(\sigma_i^2\) 表示第 \(i\) 个变量的方差，值越大，该维度上的分布越分散。 - 非对角线元素 \(\sigma_{ij}\) 表示变量 \(X_i\) 和 \(X_j\) 的协方差，控制分布的倾斜方向和相关性。 - 矩阵行列式 \(|\boldsymbol{\Sigma}|\) 反映分布的总体离散程度：行列式越大，分布越扁平化。 #### 直观解释 - 二维情形下，等高线为椭圆，\(\boldsymbol{\mu}\) 决定椭圆中心，\(\boldsymbol{\Sigma}\) 决定椭圆的长短轴方向、长度和旋转角度。 - 当 \(\boldsymbol{\Sigma}\) 为对角矩阵时，各维度独立，等高线椭圆的主轴与坐标轴对齐；非对角元素非零时，椭圆倾斜，表示变量间存在相关性。如图2[^2]。 ![alt text](figures/13.png)
图2：二元正态分布图像
## 二、高斯混合模型（GMM）原理 ### 1. 模型引入 在实际问题中，数据往往呈现**多模态分布**特征（如图3、图4[^3]），单一正态分布无法描述此类复杂结构。高斯混合模型（Gaussian Mixture Model, GMM）通过多个高斯分布的线性组合来建模复杂分布： \[ p(\boldsymbol{x}) = \sum_{k=1}^K \pi_k \mathcal{N}(\boldsymbol{x}|\boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k) \] 其中： - \(K\) 为高斯成分个数 - \(\pi_k\) 为混合系数（权重），满足 \(\sum_{k=1}^K \pi_k = 1\) - \(\mathcal{N}(\cdot)\) 为第\(k\)个高斯成分的概率密度函数 ![多模态数据示意图1](figures/14.png)
图3：多模态分布数据示意图1

### 2. 模型求解（EM算法推导） #### 问题建模 定义观测数据 \(X = \{\boldsymbol{x}_1, ..., \boldsymbol{x}_N\}\)，引入**隐变量** \(Z = \{z_1, ..., z_N\}\)，其中 \(z_i \in \{1,...,K\}\) 表示样本 \(\boldsymbol{x}_i\) 所属的高斯成分。构建完全数据对数似然函数： \[ \ln p(X,Z|\boldsymbol{\theta}) = \sum_{i=1}^N \ln \pi_{z_i} + \sum_{i=1}^N \ln \mathcal{N}(\boldsymbol{x}_i|\boldsymbol{\mu}_{z_i}, \boldsymbol{\Sigma}_{z_i}) \] #### E步：计算后验分布 根据当前参数 \(\boldsymbol{\theta}^{(t)}\) 计算隐变量后验概率（响应度）： \[ \gamma(z_{ik}) = p(z_i=k|\boldsymbol{x}_i, \boldsymbol{\theta}^{(t)}) = \frac{\pi_k^{(t)} \mathcal{N}(\boldsymbol{x}_i|\boldsymbol{\mu}_k^{(t)}, \boldsymbol{\Sigma}_k^{(t)})}{\sum_{j=1}^K \pi_j^{(t)} \mathcal{N}(\boldsymbol{x}_i|\boldsymbol{\mu}_j^{(t)}, \boldsymbol{\Sigma}_j^{(t)})} \] #### M步：参数更新 最大化Q函数 \(Q(\boldsymbol{\theta}, \boldsymbol{\theta}^{(t)}) = \mathbb{E}_Z[\ln p(X,Z|\boldsymbol{\theta})]\)，得到参数更新公式： 1. **更新混合系数**： \[ \pi_k^{(t+1)} = \frac{1}{N}\sum_{i=1}^N \gamma(z_{ik}) \] 2. **更新均值向量**： \[ \boldsymbol{\mu}_k^{(t+1)} = \frac{\sum_{i=1}^N \gamma(z_{ik})\boldsymbol{x}_i}{\sum_{i=1}^N \gamma(z_{ik})} \] 3. **更新协方差矩阵**： \[ \boldsymbol{\Sigma}_k^{(t+1)} = \frac{\sum_{i=1}^N \gamma(z_{ik})(\boldsymbol{x}_i-\boldsymbol{\mu}_k^{(t+1)})(\boldsymbol{x}_i-\boldsymbol{\mu}_k^{(t+1)})^\top}{\sum_{i=1}^N \gamma(z_{ik})} \] ### 3. 算法流程 1. 初始化参数 \(\{\pi_k, \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k\}\) 2. **E步**：计算各样本对高斯成分的响应度 \(\gamma(z_{ik})\) 3. **M步**：根据响应度更新模型参数 4. 重复步骤2-3直至收敛（似然函数变化量小于阈值） 三维空间中GMM参数迭代过程可视化如图5[^4]。 ![EM算法收敛过程示意图](figures/16.gif)
